# Финальная реконструкция Game-Seawar

Собрана на основании предоставленного дампа: 209 страниц / 5963 сетевых запросов. В реестре сохранены 213 уникальных route+query комбинаций и 437 asset URL.

## Что внутри
- реальные захваченные HTML сохранены в `captured/`;
- маршруты GitHub Pages создаются как каталоги `route/index.html`;
- query-варианты читаются браузером;
- единое локальное состояние игрока через localStorage;
- модульная структура `js/`, `data/`, `css/`;
- `assets-manifest.json` и `scripts/download_assets.py` для восстановления бинарных ассетов из их исходных URL.

## Ассеты
Сам `requests.json` содержит URL/MIME, но не байты картинок. Поэтому бинарные файлы нельзя честно извлечь из предоставленного metadata-дампа. На машине с доступом к исходному домену запустите `python3 scripts/download_assets.py`.

## Важно
Это функциональная статическая реконструкция под GitHub Pages. Серверные PHP/API-операции исходной игры заменены клиентским состоянием там, где исходный серверный ответ отсутствует в материалах.
